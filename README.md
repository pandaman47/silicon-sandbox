# silicon-sandbox
Verilog &amp; SystemVerilog RTL designs: FIFOs, UART, SPI, AXI, pipelined processors and more, each with self-checking testbenches and simulation waveforms.
silicon-sandbox is where I design, simulate, and verify digital hardware at the RTL level.
Each project includes synthesizable Verilog/SystemVerilog source, a testbench, simulation waveforms, and notes on the design decisions behind it. 
Projects progress from fundamental building blocks to larger systems as I build toward a career in RTL design.
